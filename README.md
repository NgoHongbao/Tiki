# Falling Love 💗

Một trang web tình cảm dạng animation, tối ưu cho điện thoại.

## Chạy thử
Mở `index.html` trực tiếp hoặc chạy bằng một static server.

## Sửa nội dung
- `index.html`: tiêu đề và các lời nhắn chính.
- `script.js`: thay `CONFIG.typeText` và `CONFIG.rainWords`.
- `style.css`: màu sắc, hiệu ứng và bố cục.

Made for Bắp.
